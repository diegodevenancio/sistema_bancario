# 🏦 Sistema Bancário em Python

Projeto desenvolvido durante os estudos de **Python**, com o objetivo de praticar lógica de programação, estruturas de controle, funções e implementação de regras de negócio.

O projeto simula operações básicas de um sistema bancário por meio de uma aplicação executada no terminal.

## 🚀 Funcionalidades

O sistema permite realizar operações como:

* 💰 Depósito
* 💸 Saque
* 💵 Consulta de saldo
* 📋 Controle das operações realizadas
* 🔄 Interação com o usuário por meio do terminal

## 🛠️ Tecnologias utilizadas

* Python
* Lógica de programação
* Estruturas condicionais
* Estruturas de repetição
* Funções
* Manipulação de variáveis e dados

## 📚 Evolução do projeto

O repositório contém diferentes versões desenvolvidas durante o processo de aprendizagem:

* `desafio_projeto_aula_2.py` — primeira versão do desafio.
* `desafio_projeto_sistema_bancario_v2.py` — evolução da implementação.
* `desafio_projeto_sistema_bancario_v3.py` — versão posterior com melhorias e código comentado.

A manutenção das diferentes versões permite acompanhar a evolução da implementação e dos conhecimentos adquiridos durante o desenvolvimento.

## 🎯 Objetivo

Praticar conceitos fundamentais de programação em Python e desenvolver a capacidade de transformar regras de negócio em uma aplicação funcional.
